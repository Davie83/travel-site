**{{siteName}}**（以下称"本站"）重视您的隐私。本页说明本站会收集什么、为什么收集。

## 1. 收集的信息

本站没有账号系统，也没有登录功能。**不收集姓名、电话等可直接识别个人身份的信息。**

但以下信息可能会被自动记录：

- IP 地址、浏览器类型、设备类型、访问时间
- 浏览的页面、来源链接

如果您通过[联系页面](contact)发送邮件，您的邮箱地址和内容仅用于回复，处理后即删除。

## 2. 表情反应

点击文章底部的表情时，会保存以下内容：

| 保存项 | 说明 |
|---|---|
| 访客 ID | 在您浏览器中随机生成的值（UUID）。不与姓名、邮箱、IP 关联，无法识别您的身份。 |
| 文章地址 | 您对哪篇文章做了反应 |
| 表情类型 | 您点了哪一个 |
| 时间戳 | 用于防止重复点击和机器刷量 |

- 这些**仅用于防止同一浏览器重复计数**。
- 访客 ID 保存在浏览器的 `localStorage` 中。**清除站点数据即会删除**，下次会生成新的随机值。
- 反应记录保存在 **Supabase Inc.** 的数据库中，服务器可能位于韩国境外。
- 如果您从不点击表情，以上内容都不会被保存。

## 3. 使用目的

- 了解哪些内容对读者有帮助，以便继续改进
- 投放和衡量广告效果
- 表情反应的去重与统计
- 回复您的邮件

## 4. Cookie 与浏览器存储

本站可能使用 Cookie 进行访问统计和广告投放，并使用 `localStorage` 支持以下两项功能。

- **表情反应** —— 用于显示你点过哪个表情的访客标识
- **收藏** —— 你收藏的文章列表

**两者都只保存在你自己的设备上，不会发送到服务器。** 站点运营者无法知道任何访客收藏了什么。

您可以在浏览器设置中拒绝或删除 Cookie 与站点数据。这不会影响文章阅读，只是已点击过的表情和收藏列表不再保留。

## 5. 广告 — Google AdSense

本站通过第三方广告服务商 **Google** 的 AdSense 展示广告。

- 包括 Google 在内的第三方服务商会使用 Cookie，根据您此前访问本站及其他网站的记录投放广告。
- 您可以在 [Google 广告设置](https://www.google.com/settings/ads)中关闭个性化广告。
- 如需更广泛地退出第三方服务商的 Cookie，请访问 [aboutads.info](https://www.aboutads.info/choices/)。

详情请参阅 [Google 的广告政策](https://policies.google.com/technologies/ads)。

## 6. 访问统计

本站可能使用 Google Analytics 了解访问情况。数据经匿名化处理，仅用于统计。您可以通过[浏览器插件](https://tools.google.com/dlpage/gaoptout)拒绝收集。
