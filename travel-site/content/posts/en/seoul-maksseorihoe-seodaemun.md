**This is a sashimi restaurant a very short walk from Seodaemun Station.** I meant to order the lunch set, but ended up with the premium set, which comes with a bit more.

## Lunch set vs. premium set — the difference is grilled eel and abalone

The **lunch set is 30,000 KRW per person, the premium set 40,000 KRW**. I later found out that ordering the premium set adds a full plate of **seasoned grilled eel** and a **large steamed abalone (one per person)**. For a 10,000 KRW gap, that's not a bad trade.

![The entrance to Makssaeorihoe Seodaemun — near Seodaemun Station, with the restaurant's name and phone number on the sign and a menu board posted beside it](/assets/img/seoul-maksseorihoe-seodaemun-storefront.jpg)

## The sides are ordinary, but the main dish is the star

It's not a place with a huge spread of side dishes. But the **aged sashimi** at the center of the set eats well for a lunch — the impression is a kitchen that puts its effort into the main dish rather than the sides.

## My takeaway — the lunch set alone is probably enough

Having actually tried the premium set, I think the **regular lunch set would have been enough.** The extra eel and abalone are nice, but for a lunch meal, the aged sashimi in the lunch set alone was satisfying. If you want to save a bit, go with the lunch set.

## The private-room layout makes it quiet

The restaurant is set up with **private rooms**, so it's a good spot for a quiet, clean lunch with friends. It's also very close to Seodaemun Station, so it's easy to reach.

## For foreign visitors

- **Aged sashimi (sukseonghoe)** is raw fish aged for a set period to deepen its umami — a different, richer flavor than fresh-cut sashimi
- **Jeongsik** is a full set meal — a main dish served with several side dishes, rice, and soup
- The private-room layout makes it easy to talk quietly with your group while you eat

## Who this is for

- ✅ Anyone who wants a quiet lunch meeting near Seodaemun Station
- ✅ Anyone who wants to enjoy aged sashimi as a clean, simple set meal
- ✅ Anyone watching their budget — the lunch set alone is enough
- ⚠️ If you want a lavish spread of side dishes — the sides here are fairly ordinary
- ⚠️ If grilled eel and steamed abalone sound tempting, the premium set is also an option
